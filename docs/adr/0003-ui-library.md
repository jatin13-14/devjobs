# ADR 0003: Proposed Ant Design foundation

- Status: Proposed — owner confirmation required
- Date: 2026-11-05

## Context
The product needs consistent forms, tables, navigation and dashboard patterns. The owner requested atomic UI composition and a consistent visual system.

## Proposal
Use Ant Design as the base component library, with centralized project-owned design tokens and wrappers.

## Consequences
- Faster delivery of accessible, consistent controls.
- Avoid mixing multiple component libraries.
- Customize theme centrally; do not scatter inline styles.
- Revisit only if product-specific design requirements cannot be met cleanly.
